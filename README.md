## Antes de usar este material

- **Presupuesto.** Ninguna empresa tiene presupuesto confirmado. Todas están "pendiente de validar".
- **Cartera.** El cruce con la cartera de clientes y prospectos de DRA está **pendiente** porque no tuvimos acceso a ella.
- **Funciones de IAVINCHI.** Las que mencionan los guiones deben confirmarse con el equipo de producto antes de publicar.
- **Demostraciones.** Deben usar datos de ejemplo identificados como tales.
- **Contactos.** Usar solo los contactos comerciales publicados que figuran en cada ficha.
